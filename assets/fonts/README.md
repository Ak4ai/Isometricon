# Fontes empacotadas

Estas fontes são carregadas por `src/core/fonts.py` e empacotadas pelo
`scripts/build.py` junto com `assets/`.

- **Inter** — https://rsms.me/inter/ — SIL Open Font License 1.1.
  Arquivo variável usado no texto de interface, em pesos 400–700.
- **JetBrains Mono** — https://www.jetbrains.com/lp/mono/ — SIL Open Font License 1.1.
  Arquivo variável usado em coordenadas, chat e rótulos técnicos.

As licenças completas estão em `OFL-Inter.txt` e `OFL-JetBrainsMono.txt`.
Os arquivos vieram do repositório oficial do Google Fonts.
