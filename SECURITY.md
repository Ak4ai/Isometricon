# Política de Segurança - Isometricon

## Versões Suportadas

| Versão | Suportada          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Relato de Vulnerabilidades

Caso encontre alguma vulnerabilidade no código ou nas bibliotecas de baixo nível, abra uma [Issue Privada de Segurança](https://github.com/Ak4ai/Isometricon/security/advisories/new) ou entre em contato diretamente com os mantenedores do projeto no CEFET-MG.
