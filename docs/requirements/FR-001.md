## Descrição

### Texto do Requisito

> O sistema deve abrir uma janela redimensionável com contexto OpenGL 3.3 Core, habilitar teste de profundidade, descarte de faces traseiras e limpeza de cor/profundidade por quadro.

### Condições de Aplicação

- Driver com OpenGL 3.3 Core; execução de `python src/main.py`.
