## Descrição

### Texto do Requisito

> O editor deve permitir gerar voxels de um objeto a partir de regras declarativas simples por coordenada, com prévia antes de aplicar, inspirado no modo de criação por código do Replicube, sem exigir runtime de linguagem externa.

### Condições de Aplicação

- Modo editor; funcionalidade habilitada; expressão/regra válida.
