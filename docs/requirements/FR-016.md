## Descrição

### Texto do Requisito

> O sistema deve impedir que o token atravesse blocos sólidos, aplicar gravidade com velocidade máxima de queda, permitir subir um bloco quando o token já está apoiado e tratar água como não sólida.

### Condições de Aplicação

- Movimento horizontal ou queda; provedor de blocos disponível.
