# Neblina de ambientação — plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** uma neblina de cena configurável no `/mestre` (quantidade, cobertura, altura, onde, vento, tom, presets) e o
painel dividido em abas.

**Architecture:** os campos novos moram em `Ambience` (salvos com o mundo). Um módulo novo `src/rendering/mist.py`
monta, dos chunks carregados, um mapa 2D em volta do jogador (altura do chão e "perto de água/árvore") e o manda para
a GPU; o `world_textured.frag` integra a densidade da neblina no raio da câmera até o ponto (16 passos). O painel
ganha abas, cada uma com a sua altura.

**Tech Stack:** Python, NumPy, SciPy (ndimage), PyOpenGL, GLSL 330, Pillow (painel).

**Spec:** `docs/superpowers/specs/2026-11-25-neblina-design.md`

## Global Constraints
- Campos novos de `Ambience` (todos int): `mist` 0–100 (0), `mist_cover` 0–100 (100), `mist_height` 1–40 (6),
  `mist_where` 0 toda parte / 1 água e árvores (0), `mist_wind` 0–100 (30), `mist_tone` 0 fria / 1 neutra / 2 quente (1).
- Abas: `Luz`, `Neblina`, `Guerra`, `Cenas`. A aba não vai para o save.
- A névoa de distância continua (`fog`), na aba Neblina, com o rótulo "Névoa de distância".
- Textos em português, como o resto do jogo.

## Review Focus
- Mundo salvo antes (sem os campos `mist*`): carrega com os padrões, neblina desligada.
- `mist_cover` 0 com `mist` > 0: nenhuma neblina (não um véu fraco no mapa todo).
- Caverna / cômodo: a neblina de fora não entra (desligada em `underground_mode` e com o cômodo revelado).
- Jogador andando longe: o mapa recentra sem travar o quadro (recalcula no máximo a cada recentrada ou mudança de chunks, throttled).
- Painel numa janela baixa: cada aba mede a própria altura e encolhe para caber.
